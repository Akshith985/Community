GuildHQ Landing Page - Full Feature Pack
========================================

Contents:
- index.html: Responsive mobile landing page with modal-based Auth (Email/Pass, Google, GitHub) & Formspree form.
- firebase-config.js: Complete Firebase setup supporting Email/Password + OAuth providers.
- 404.html: Custom pixel art Error 404 page.
- terms.html: Terms & Conditions page.
- copyright.html: Copyright & legal notice page.

Execution:
1. Ensure Email/Password, Google, and GitHub sign-in methods are enabled in Firebase Console (hackathon-c348c).
2. Host on a local web server (`npx serve` or Live Server) for JS module support.
